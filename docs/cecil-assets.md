# 세실 루미너스

프로필 8325, 기본 정보 8323, 스킬 아이콘 8327, 광룡탄 8329, 선홍빛 폭풍 각성 2~6단 8331~8339, 클래스 트리 8341, 궁그닐 설명/카드 8343, 무기 각성 1~6단 8345~8355를 기준으로 등록.

- 초상화/썸네일: 8325 (295,195,595,595), 원본에서 각각 600×800 / 420×560 출력.
- 패시브: 8327 (763,548,849,634), 필살기: (1069,436,1156,523).
- 궁그닐: 8343 (954,186,1166,500). 내장 이미지 편집으로 레벨·별·자물쇠만 제거하도록 요청. 창 디자인·각도·위치·색상·광원·전체 테두리 보존, 가려진 자루 끝은 추정 복원. 결과 `/icons/weapons/gungnir.png`.
- 기존 파이크/템플러/제너럴/하이템플러/법왕기사/마샬과 경직 재사용.
- 패시브 5~6단계는 추가 이동 포함. 화면에 없는 지속 시간이나 횟수 제한은 추가하지 않음.
- 무기 각성 능력치는 Lv50 기준. 필살기는 발현 없는 기본 단계로 등록.
