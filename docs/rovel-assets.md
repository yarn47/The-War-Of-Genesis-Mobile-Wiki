프로필 8217, 희귀·자유의 불꽃 8219, 클래스 트리 8221. 파이터·나이트·팔라딘·로얄나이트·크루세이더·인퀴지터는 기존 데이터와 이미지를 재사용한다.
뒤틀린 생존 Lv.1~6은 8223/8225/8227/8229/8231/8233. 발동 체력 기준은 40/40/50/50/60/60% 이하, 받는 피해 비율은 70/60/60/55/55/50%, 도망친 후 체력 회복은 15/20/25/30/35/40%이다.
피해 비율은 감소량이 아닌 실제 받는 비율로 기록했다. 반격하지 않고 이동 가능한 범위 내에서 도망치며 턴당 1번 발동한다. 원문에 없는 회복 기준·도망 방향·거리 조건은 추정하지 않았다.
