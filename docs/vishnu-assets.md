초상화는 원본에서 각각 생성했고 고유 패시브의 U 표식과 프레임을 보존했다.
프로필 8123, 등급·속성 8125, 클래스 트리 8127. 메이지·매지션·서머너·아크메이지·소서러·서먼로드는 기존 데이터를 재사용한다.
현자의 지혜 Lv.2~6은 8129/8131/8133/8135/8137, Lv.6 하단 아케인 설명은 8139로 확인했다.
Lv.2/3은 턴 종료 시 60/80% 확률로 버프 1개를 획득하며, Lv.4~6은 확률 조건 없이 버프 1개를 획득한다. 공격하거나 스킬 사용 시 보유 버프 1개당 주문력 증가량은 5/6/8/9/10%이다.
Lv.2~3의 버프 후보는 레인지 업·헤이스트·스펠버스트, Lv.4~5에는 커밋, Lv.6에는 아케인이 추가된다. 모두 2턴 지속하며 후보별 추첨 확률은 추정하지 않았다.
기존 레인지 업(스킬 사거리 +1)·헤이스트(이동 거리 +2)는 재사용한다. 스펠버스트는 범위 스킬 사용 시 주문력 +20%, 커밋은 전투 공격 시 대상이 받는 피해 +20%, 아케인은 스킬 사용 시 사용한 TP 반환으로 기록했다.
출시일 2024-01-09, 출현작 창세기전2, 필살기·전용무기 없음은 사용자 공통 지시를 따른다. 원본 첨부는 임시 경로로 영구 보관을 보장하지 않는다.
