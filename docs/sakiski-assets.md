초상화는 각각 원본에서 생성하고 고유 패시브 U 표식은 보존했다. 프로필 8143, 희귀·욕망의 그림자·현재 클래스 나이프마스터는 8145로 확인했다.
8147~8153은 좌하단 초상화가 사키스키와 다른 캐릭터인 클래스 자료다. 따라서 사키스키의 전체 클래스 트리는 확정하지 않고 현재 확인된 나이프마스터만 등록했다. 전용 클래스 트리 화면을 추가 확인해야 한다.
나이프마스터 난도질 1/2(8149/8153), 회선팔검(8151)은 기존 rogue_line 데이터와 일치해 기존 효과·이미지를 재사용했다. 공유 클래스의 부모 관계는 수정하지 않았다.
숨은 재능 Lv.1~6은 8155/8157/8159/8161/8163/8165. 치명타 확률 증가량 15/20/20/25/25/30%. 자신보다 공격력이 적은 상대와 전투 시 발동한다. 처치 시 은신 2턴, Lv.3~4 추가 이동, Lv.5~6 턴당 한 번 추가 행동으로 기록했다.
은신은 기존 정의를 재사용했다. 선제 공격의 기존 공유 정의는 2턴이지만 이 패시브 화면은 1턴·해제 불가이므로 캐릭터 설명에 명시하고 공유 정의는 덮어쓰지 않았다.
출시일 2024-01-09, 출현작 창세기전2, 필살기·전용무기 없음은 사용자 공통 지시를 따른다. 원본 첨부는 임시 경로로 영구 보관을 보장하지 않는다.
