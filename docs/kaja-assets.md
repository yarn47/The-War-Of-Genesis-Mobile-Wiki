초상화는 각각 원본에서 생성하며 모자 끝보다 얼굴 구도를 우선했다. 패시브 U 표식과 사각 프레임을 보존했다.
프로필 7997, 등급·속성 7995, 클래스 트리 7999. 클래스는 모두 기존 데이터를 재사용한다.
꿈꾸는 걸음 Lv.2~6은 8001/8003/8005/8007/8009 기준이다. 대응 버프 1~5는 이동력 +1, 공격력·주문력·치명타 확률 +5/7/10/12/15%, 해제 불가이다. 게임 시작 시 버프를 얻으며, 체력 50% 이하에서 전투 공격 시 추가 행동을 얻고 버프가 사라진다. 매 턴 재부여나 추가 지속시간은 추정하지 않았다.
출시일 2024-01-09, 출현작 창세기전2, 필살기·전용무기 없음은 사용자 공통 지시를 따른다.
원본 첨부는 임시 경로이므로 영구 보관을 보장하지 않는다. 결과 PNG와 크롭 좌표는 저장소에 보관한다.
