# 캐릭터 이미지 크롭 작업 가이드

아이린 사르데스와 아리아나 위버 Jr.에 실제 적용한 방법을 기준으로 한다.
원본 스크린샷에서 이미지를 잘라 사용하며, 새 캐릭터의 원본 해상도와 UI 배치가 다르면 좌표를 다시 잡는다.

## 1. 기본 원칙

- 클래스·스킬·초상화는 **원본 크롭**이다. AI로 다시 그리지 않는다.
- 원본은 보존하고 결과를 별도 PNG로 저장한다. 승인된 기존 이미지는 일괄 수정하지 않는다.
- 선택된 클래스의 파란 발광 테두리, 연결선, 툴팁에 가린 부분을 피한다. 같은 클래스가 선택되지 않은 다른 사진을 우선 사용한다.
- 투명 처리할 때 내부의 어두운 음영까지 지우지 않는다. 검은색 전체를 제거하는 방식은 금지한다.
- 무기 카드의 Lv·별·자물쇠 제거만 별도의 AI 보정 작업이다. 가려진 무기 부분의 복원은 추정임을 명시한다.
- 임시 첨부 경로와 `/tmp`의 스크립트는 영구 보관소가 아니다. 재작업하려면 원본 사진을 별도로 보관해야 한다.

## 2. 저장 위치와 결과 크기

저장소 루트의 `public/icons/` 아래에 저장한다. 데이터에서 참조할 때는 `public`을 빼고 `/icons/...`로 적는다.

## 3. 좌표 읽는 법

아래 좌표는 Pillow의 `(left, top, right, bottom)` 형식이다.

- 원점은 이미지 왼쪽 위, 오른쪽으로 x 증가, 아래쪽으로 y 증가.
- 너비는 `right - left`, 높이는 `bottom - top`이다.
- 오른쪽·아래 경계는 포함하지 않는다.
- 채팅 화면에 축소 표시된 사진이 아니라 **원본 파일 해상도**를 기준으로 한다.
- 아래 아이린·Jr. 예시는 원본 **1280×810** 사진에서 측정했다.

## 4. 종류별 자르는 방법

### 클래스 엠블럼

1. 툴팁이나 선택 효과가 없는 사진에서 원의 중심을 찾는다.
2. 금색 원 테두리가 꽉 차는 정사각형으로 자른다. 바깥 연결 노드와 연결선은 제외한다.
3. 원형 알파 마스크를 적용한 뒤 146×146으로 조정한다.
4. 어두운 배경 위에서 밝은 배경 초승달, 연결선 잔상, 잘린 원 테두리가 없는지 확인한다.

아이린은 중심에서 좌우·상하 45px, 즉 90×90 크롭을 사용했다. 이 수치는 해당 원본용이지 모든 사진의 고정값이 아니다.

### 클래스 패시브·액티브·고유 패시브

- 스킬 설명 팝업 그림보다 ‘획득 스킬’에 있는 사각 타일을 우선 사용한다.
- 타일 테두리와 우측 상단 P/A/U 표식을 보존한다. 원형으로 미리 자르지 않는다.
- 고유 패시브는 선명한 스킬 화면이 가장 좋다. 아이린은 기존 캐릭터 정보 화면의 U 타일을 사용했다.
- 발현 트리의 원형 표시와 확대는 화면 코드가 담당한다. 원본 PNG에 같은 확대나 잘림을 중복 적용하지 않는다.

### 초상화·썸네일

- 두 파일을 원본에서 각각 자른다. 이미 잘라낸 상세 초상화에 원본 좌표를 다시 적용하지 않는다.
- 얼굴 크기와 눈높이를 기존 승인 이미지(예: 자드)와 비교한다.
- 머리장식 끝만 맞추면 얼굴이 너무 낮아질 수 있다.
- 3:4 비율을 유지하고, 실제 카드의 `object-cover` 적용 후에도 이마·턱이 과하게 잘리지 않는지 확인한다.

### 아티팩트

1. 둥근 구슬뿐 아니라 바깥 금속 장식까지 포함해 자른다.
2. 장식의 실제 외곽선을 따라 다각형 마스크를 만든다.
3. 내부의 검정·회색 음영은 그대로 보존한다.
4. 대략 144×154로 맞추고 투명 PNG로 저장한다.

단순 원형 마스크로 장식을 자르거나, 전역 색상 임계값으로 어두운 부분을 지우지 않는다. 아이린의 세 구슬은 공통 외곽 형상이어서 같은 마스크를 사용했지만 새 아티팩트에는 다시 측정한다.

### 전용무기

- 카드 전체와 금색 프레임을 포함한다. 정사각형으로 자르지 않는다.
- 먼저 원본 카드 크롭을 저장한 다음, AI 보정 도구에 이 크롭 하나만 편집 대상으로 제공한다.
- 변경 범위는 Lv 표시·희귀도 별·자물쇠와 그 배경만이다. 무기 디자인, 위치, 비율, 색, 프레임은 유지한다.
- 보정 결과를 원본과 비교해 장식·무기 끝·배경이 불필요하게 바뀌지 않았는지 확인한다.
- 최종 파일은 프로젝트의 `public/icons/weapons/`에 복사한다. 생성 도구의 임시 결과 경로를 직접 참조하지 않는다.

보정 요청 예시:

> 제공한 무기 카드의 Lv 숫자, 아래쪽 별, 자물쇠와 그 사각 배경만 제거한다. 해당 영역은 주변 금갈색 배경으로 연결하고, 글자에 가린 무기 끝만 원래 형태를 따라 추정 복원한다. 원본 무기의 디자인·색·위치·비율, 금색 테두리와 모서리 장식은 유지한다. 확대·회전·재디자인·전체 선명화는 하지 않는다. 카드의 네 변을 모두 포함한 세로 이미지 한 장을 출력한다.

## 6. Pillow 크롭 예시

Python과 Pillow가 있는 환경에서 사용한다. 입력·출력 경로는 보관한 실제 파일에 맞춘다. 실수로 기존 결과를 덮어쓰지 않도록 출력 파일이 있으면 중단한다.

```python
from pathlib import Path
from PIL import Image, ImageDraw

def crop_asset(source, destination, box, size=None, circle=False, polygon=None):
    source, destination = Path(source), Path(destination)
    if destination.exists():
        raise FileExistsError(destination)
    if circle and polygon:
        raise ValueError('원형과 다각형 중 하나만 지정하세요.')

    with Image.open(source) as original:
        left, top, right, bottom = box
        if not (0 <= left < right <= original.width
                and 0 <= top < bottom <= original.height):
            raise ValueError('원본 해상도와 크롭 좌표를 확인하세요.')
        im = original.convert('RGBA').crop(box)

    if circle or polygon:
        # 4배 크기에서 그린 뒤 축소해 외곽 계단 현상을 줄인다.
        mask = Image.new('L', (im.width * 4, im.height * 4), 0)
        draw = ImageDraw.Draw(mask)
        if circle:
            draw.ellipse((0, 0, mask.width - 1, mask.height - 1), fill=255)
        else:
            draw.polygon([(x * 4, y * 4) for x, y in polygon], fill=255)
        im.putalpha(mask.resize(im.size, Image.Resampling.LANCZOS))

    if size:
        im = im.resize(size, Image.Resampling.LANCZOS)
    destination.parent.mkdir(parents=True, exist_ok=True)
    im.save(destination, format='PNG')

# 먼저 임시 결과로 검토한 뒤 승인된 파일을 public/icons/에 둔다.
crop_asset('originals/3-6133.jpg', 'preview/sister.png',
           (228,124,318,214), size=(146,146), circle=True)
crop_asset('originals/4-6135.jpg', 'preview/heal.png',
           (897,230,969,302))
```

이 예시는 불투명 게임 스크린샷을 입력으로 삼는다. 이미 투명한 PNG를 재가공할 때는 기존 알파도 보존하도록 별도 처리해야 한다.

## 8. 완료 전 확인

- [ ] 모든 결과를 한 장에 모은 검토용 이미지로 비교한다. 투명 외곽은 어두운 배경에서도 확인한다.
- [ ] 클래스 원이 찌그러지거나 연결선·선택 광원이 남지 않았는지 확인한다.
- [ ] 스킬의 P/A/U 표식과 테두리가 의도대로 남았는지 확인한다.
- [ ] 아티팩트 장식 끝과 내부 음영이 보존되었는지 확인한다.
- [ ] 초상화의 얼굴 크기·눈높이를 기존 캐릭터와 비교한다.
- [ ] 무기 카드가 전체 세로 비율로 보이고 끝부분이 잘리지 않는지 확인한다.
- [ ] 실제 목록·상세·클래스 선택·발현·아티팩트·무기 화면에서 확인한다. 원본 PNG 검토만으로 끝내지 않는다.
- [ ] 데이터에 적힌 `/icons/...` 경로가 실제 파일과 일치하는지 확인한다.
- [ ] `npm run build`와 `git diff --check`를 통과한다.
- [ ] 임시 크롭·원본 사진·개인 경로·검토용 모음 이미지는 실수로 커밋하지 않는다.

이미지 작업 완료와 커밋·푸시·배포는 별개다. 사용자가 요청한 범위까지만 진행한다.
