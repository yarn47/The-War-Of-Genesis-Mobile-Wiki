초상화는 각각 원본에서 생성했고 패시브 U 표식과 사각 프레임을 보존했다.
프로필 8041, 등급·속성 8045, 클래스 트리 8047. 클래스는 기존 데이터를 재사용한다. 잠금·랭크 상태는 계정 육성 상태이므로 클래스 목록에서 제외하지 않는다.
불굴의 기사 Lv.1~6: 8049/8051/8053/8055/8057/8059.
기본 방어력·받는 치유 증가 15/16/17/18/19/20%, 체력 조건 40/40/50/50/60/60% 이하, 조건부 방어력·치유 증가 30/32/34/36/38/40%, 반격 회복은 방어력의 35/40/45/50/55/60%이다. 원문대로 1턴에 한 번 발동 문구를 보존하며 기본·조건부 수치를 임의로 합산하지 않는다.
출시일 2024-01-09, 출현작 창세기전2, 필살기·전용무기 없음은 사용자 공통 지시를 따른다.
원본 첨부는 임시 경로이므로 영구 보관을 보장하지 않는다. 결과 PNG와 크롭 좌표는 저장소에 보관한다.
