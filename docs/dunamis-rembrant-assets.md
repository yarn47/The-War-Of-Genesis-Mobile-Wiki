# 듀나미스 램브란트 자료 및 이미지 검증

## 입력 근거

- 사용자 스크린샷 9057~9151. 출시일은 카림 니디아(2024-04-16)의 2주 뒤인 2024-04-30, 출현작은 사용자 지정 창세기전2.
- 노발현 축성간열파 계수 120%는 사용자 직접 확인. 발현 1/3/5는 130/140/150%.
- 각성 3~6, 발현 2/4/6 패시브, 화이트나이트·어세틱, 아티팩트, 무기 1~6단 반영.
- 레벨 57 화면 능력치는 기본 능력치로 입력하지 않음.
- 기존 디펜더·아머나이트·팔라딘·인퀴지터, 최상의 상태, 호위·엄폐·통제 영역 재사용.
- 기존 억제(영구·해제 불가)는 보존하고 억제 (고연섬)(2턴·스킬제어)을 별도 등록.
- 해방된 정신의 호위는 인접 아군. 디버프 수집 범위는 각성 3의 1바퀴, 각성 4/5의 2칸, 각성 6 및 발현의 2바퀴를 구분.
- 영광의 횃불 오라는 2턴이나 효과 툴팁은 영구·해제 불가. 궁의 호위 범위 증가 지속시간은 원문에 없어 추가하지 않음.
- 불안감은 2턴·해제 불가만 명시. 압박감 설명 외 별도 수치나 제어 효과를 만들지 않음.
- 클래스명은 원본 표기 어세틱 사용.

## 검증

- API 전체 테스트 90개, 프런트 테스트 5개 통과.
- 프런트 빌드 및 SQL 생성 검증 통과. SQL은 실제 DB에 실행하지 않음.
- DB 대신 임시 로컬 데이터 서버로 목록 썸네일, 상세 초상화/진영/날짜, 두 신규 클래스, 발현 6단, 아티팩트 두 종류 전 단계, 무기 능력치 및 전용/일반 효과 전 단계를 확인.
- 억제 (고연섬) 툴팁이 2턴·스킬제어로 표시됨을 확인.
- 기존 데이터 변경 없이 캐릭터별 파일 추가. 커밋·푸시·배포 미실행.
