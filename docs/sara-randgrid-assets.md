# 사라 랜드그리드 자료 기록

## 근거와 처리

- 사용자 스크린샷 8593~8719 기준. 출시일은 사용자 지정 낭천 +14일인 2024-02-20, 출현작은 창세기전2.
- 프로필 8593, 고유 패시브 각성 8597~8611 및 발현 8617~8621, 초필살기 8615/8623~8627, 아티팩트 8629~8651, 실피드 8653~8677, 클래스 8679~8713 및 라이트닝 블레이드 8719.
- 풍아열공참 기본 수치는 원본 미제공. 사용자의 명시적 요청에 따라 발현 1의 30%에서 단계 차이 5%p를 뺀 25%로 입력했다. 나머지 효과는 발현 1과 동일하며 화면 본문에도 추정값임을 표시한다.
- 전장의 삭풍은 각성 단계에만 ‘이번 턴에 적에게 피해를 줬다면’ 조건이 있다. 발현 2/4/6에서는 해당 조건이 없고, 발현 6은 게임 시작 시 사수 7 획득이 추가된다.
- 실피드의 추가 호위는 1~4성 1회, 5~6성 2회. 각성별 레벨 50 체력/공격력만 기록하고 특화 옵션과 장비 적용 캐릭터 수치는 제외했다.
- 공용 패스파인더/스톰워커 및 헤이스트/호위 재사용. 사수 설명 안에 2칸 호위 범위를 명시하고 공용 호위 설명/지속은 수정하지 않았다.
- 공용 패스파인더의 기본 부모는 레인저이므로 캐릭터 트리에 해당 부모가 없고 유일한 1티어가 있는 경우, 화면에서만 그 1티어에 연결한다. 사라에서는 발키리 아래에 표시되며 공용 클래스 DB는 변경하지 않는다.
- 이너브레이크 분류는 기존 데이터에 대응 필드가 없어 추가하지 않았다. 스크린샷에 없는 효과 지속 시간은 추정하지 않았다.

### 실피드 편집 프롬프트

Use case: precise-object-edit. Edit target: supplied game weapon card. Remove ONLY Lv50 text, bottom rarity stars, and lower-right lock with its square background. Inpaint those tiny areas with matching golden brown background. Reconstruct only sword tip hidden by text and stars, following visible blade. Preserve exact sword design, guard, blue pommel, angle, position, proportions, colors, glow, and complete rectangular ornamental frame. No redesign, no extra ornaments, no cropping, no text. Output one complete portrait card.

## 검증

- JSON 6개 파싱, 전체 SQL 생성(경고 없음), 이미지 22개 경로 검증, 프런트 빌드, 프런트 테스트 5건(부모 연결 2건 포함), API 데이터 테스트 67건(사라 5건 포함) 통과.
- 원본 크롭 21개와 보정 무기 1개를 모음 이미지로 검토. 초상화 얼굴 크기는 기존 스트라이더와 비교.
- 운영 DB 대신 새 JSON에서 구성한 임시 API 응답으로 로컬 브라우저에서 프로필, 클래스 선택, 발현 6단, 아티팩트 펼치기, 실피드 수치 및 전용 효과 확인.
- 브라우저 자동화의 마우스 클릭이 일부 버튼에서 반응하지 않아 키보드 Enter로 전환해 상태 변경을 확인했다. 이를 앱 오류로 단정하거나 별도 변경하지 않았다.
- 운영 DB 실행 및 배포 검증은 별도 필요. 커밋·푸시·배포하지 않음.
